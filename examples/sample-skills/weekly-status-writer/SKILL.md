# Weekly Status Writer

Write status updates that respect the reader's 30 seconds.

## Structure

**Wins** — max 3 bullets, each starts with the outcome, not the activity
("Shipped X, cutting p95 latency 40%" not "Worked on X").

**In flight** — what's moving and expected landing date. Only items with
real progress this week.

**Blocked / needs input** — each blocker names WHO can unblock it and WHAT
decision or action is needed. A blocker without an ask is just a complaint.

**Next week** — max 3 commitments, phrased so next week's update can say
done/not-done unambiguously.

## Rules

1. Total length under 150 words unless the user asks for detail.
2. No filler ("continued to make progress on…"). Every line carries information.
3. Quantify where the input allows; never invent numbers.
4. Match the seniority of the audience: for execs, cut "In flight" and merge
   into Wins/Next.
